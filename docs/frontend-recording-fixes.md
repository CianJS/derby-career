## 검증

- 일반 테스트에 실제 App 설정/재로딩의 Career·Archive·마방명 보존, 서버 자금 갱신,
  같은 이름 두 은퇴 기록의 ID별 상세와 최신 정렬을 포함한다.
- v1/v2/v3 저장 로그의 Strip·Gap·Board·FOCUS·History 순위/시점/내 말 거리 및
  마커의 거리 좌표를 확인한다. 기존 로그 불변성·미래 Feed 노출 방지 검사를 유지한다.
- `tests/e2e/recording-ui.spec.ts`는 PC 1440×900 / 모바일 390×844에서 검색·정렬·개별
  상세, 설정 데이터 보존, 2035년 Career의 계약 표시, 실제 로컬 휴식/결과 전환,
  알림 키보드 포커스/닫기, 단일 오류/실제 API 재시도를 검사한다.
- 브라우저는 저장된 v1/v2/v3 로그를 화면에 재생하고 정지 시점의 실제 DOM 마커 중심,
  순위 패널·거리·Feed를 공유 `frameAt` 결과와 비교한다. 테스트 데이터 생성만 기존
  공유 시뮬레이터를 사용하며 제품 화면에 Mock 응답이나 새 엔진을 추가하지 않는다.
- 선택한 설정 보조문구의 라이트/다크 대비 4.5:1과 주요 아이콘 클릭 영역 44px,
  페이지 가로 넘침 및 스크린샷을 기존 Browser E2E CI에서 확인한다.
- `pnpm test:e2e`는 실제 PostgreSQL 테스트 DB와 Chromium을 요구한다. Node/jsdom 및
  PGlite HTTP 통합 검사는 이 실제 브라우저 검사와 별도다. 실행 결과는 PR 본문에 기록한다.

## 기존 계약의 한계

현재 Stable 응답은 id/funds/calendarDate만 제공하고 마방 이름·국가 수정 API가 없다.
설정은 읽기 전용이며 서버 이름/국가를 생성하지 않는다. 계약 정보는 ID 목록이며 만료일이
없어 날짜나 갱신 기능을 만들지 않는다. 향후 편집/만료 처리가 필요하면 Backend 계약을
먼저 확정해야 한다. 이번 수정에 필요한 Backend 변경 요청은 없다.

ChatGPT Site는 기존 비공개 정적 내보내기/Local Save만 유지한다. 공개 카탈로그를 제공하는
Next bridge와 Fastify/PostgreSQL은 Site에 배포되지 않는다.
