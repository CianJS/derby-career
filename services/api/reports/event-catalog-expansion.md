## 조사한 기존 구조와 실행 범위

- ID: 공통 `COM`, 일반 `GEN`, 특별 `SPC`, 사고 `ACC`, 히든 `HID`의 4자리 식별자. SQL PK, event revision SHA-256, revision별 선택지 ID/효과 ordinal을 사용한다.
- 카테고리: 기존 공유 타입 및 OpenAPI에 5종 모두 있다. `candidate`/`followup`/`hold`, `ready`/`needs_mapping`/`deferred`, 별도 `enabled`를 갖는다. 도입 비율 문서가 런타임 카테고리별 가중치인 것은 아니다.
- 선택지: 최대 2개, 자동 이벤트는 1개. 선택지는 자체 조건과 효과를 가진다. 원문 조건/효과와 실행용 타입은 분리된다.
- 조건: `always`, `healthy`, `training_available`, `action_is`, 스칼라 `value_range`, 육성 turn의 `turn_range`. 조건 배열은 AND이며 복합 OR·이력·적성·연령·관계 조건 타입은 없다.
- 효과: `value_delta`, 같은 달의 `action_modifier`, 잠긴 훈련 결과의 `resolved_growth_bonus`. 지능 훈련은 공유 규칙에 보조 성장 대상이 없고 결과 시점 보정을 이미 확정된 행동에 소급 적용하지 않는다.
- 발동 시점 스키마에는 6종이 있지만 서버 월간 director는 월 시작·훈련/휴식/치료 결과만 처리한다. `before_race`/`after_race`는 실행 후보에서 제외한다.

## 비활성 가져오기 보장

`events:check`는 원문을 유지하고 실행 조건/선택지/효과를 넣지 않는 `importMode: 'drafts'` packet을 생성한다. 모든 항목은 `introduction=hold`, `enabled=false`, `automatic=false`다. 변환 가능한 입력도 `deferred`로 격리하며 활성화하지 않는다. 현재 650개는 전부 `needs_mapping`이다. `weight=1`은 양수 스키마 자리만 채우며 비활성 항목의 확률이나 밸런스를 설정하지 않는다.

`events:import-drafts`는 packet과 revision/sourceDigest를 검증하고 같은 트랜잭션/advisory lock에서 upsert한다. 공통 항목·기존 검토 완료 항목·활성화된 DB 메타데이터는 보호한다. 재적용/수정 revision의 멱등성과 실패 시 전체 롤백을 검사했다. 일반 `events:import`는 격리 packet의 다른 envelope를 거부한다. 초안에는 실행 타입이 없어서 미지원 효과 일부만 실행할 수 없다. 새로 활성화하는 기능이나 API는 추가하지 않았다.

재생성:

```bash
cd services/api
npm run events:check -- seeds/events.drafts.import.json /tmp/draft-report.json /tmp/event-drafts.json
```

현재 `sourceDigest`는 `cef5bbd4c23c1cd19f3cacf3ab08c38d07314a125e313cba1b56ec38db25361d`다. JSON 보고서에는 항목별 ID·필드 경로·오류/미지원 코드가 있고, 공개 검사 입력으로 원문을 대조할 수 있다. 검사 문법/분류를 변경하면 보고서와 검토 결과를 함께 다시 확인한다.
